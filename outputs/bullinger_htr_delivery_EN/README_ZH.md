# Bullinger HTR 与地名识别：中文说明

更新日期：2026 年 10 月 14 日。本文件夹是整理后的交付包，包含可运行代码、固定的官方参考数据、实际结果和来源记录。英文说明见 `README.md`。德语、拉丁语原文及原始标注保留原样，以免影响评价。

## 目前使用什么数据

地名识别只使用官方 TEI 正文中的地名标注作为参考，当前程序不读取个人审核表，也不使用旧版人工衍生的边界规则或人名过滤规则。

官方来源：[stazh/bullinger-korpus-tei](https://github.com/stazh/bullinger-korpus-tei)，固定版本为 `dc9fb5290c210023a6a9182e8e3102c1f6dff734`。预先选定的 40 封候选信中，39 封符合要求，共有 357 个正文段落、327 个官方地名标注。用于学习地名变体的信件已排除。

这批材料已经用于分析与评价。以后根据它的错误调整程序，应视为开发实验，不能再称为全新的独立验证。

## 当前地名识别结果

| 指标 | 结果 |
|---|---:|
| 精确匹配的官方地名标注 | 200 |
| 未与官方标注精确匹配的预测 | 41 |
| 未识别出的官方地名标注 | 127 |
| 官方标注一致性 Precision | 82.99% |
| 官方标注一致性 Recall | 61.16% |
| 官方标注一致性 F1 | 70.42% |

主方案预先确定为：竞争标签 `location/person/organization`、阈值 0.8，加官方来源的地名变体词表。其他固定对照结果见 `RESULTS.md`，没有根据此次结果事后挑选最佳阈值。

这些指标衡量预测与已发布官方标注的一致性。官方标注是否穷尽所有地名尚未证实，因此未匹配的预测不能一律当作真实误报。这也不是坐标定位准确率或从手稿图像到地名的端到端准确率。当前结果尚未达到严格的 Precision ≥85% 目标。

## 如何运行

在 `bullinger-htr` 项目根目录运行：

```sh
.venv-nlp/bin/python outputs/bullinger_htr_delivery_EN/scripts/run_official_ner.py --output-dir outputs/official_ner_new_run
```

输出目录必须是尚不存在的新目录，程序不会覆盖已有结果。程序使用项目里的 `.venv-nlp` 环境和 `.cache/huggingface` 模型缓存，固定 GLiNER 模型版本为 `443d26d654e0324125a96bebd8e796c14ff2efe6`。

交付包没有重复打包模型权重。如果把包单独复制到其他电脑，需要安装依赖并取得上述固定版本的模型。依赖见 `requirements.txt`。

整理后已在本机离线完整运行验证：357 个段落的五组指标与保存结果完全一致。详见 `VERIFICATION.md`。这是复现检查，不是新增独立测试。

## 文件说明

- `scripts/`：当前官方地名识别程序及辅助模块。
- `data/`：固定参考段落、未修改的官方 XML、选样与来源审核记录、官方地名变体词表。
- `results/`：真实预测、指标、配置及漏识别记录。
- `training/`：保留的 Colab 训练、适配和重评分程序，与当前地名评价分开。
- `Bullinger_Clean_Colab.ipynb`：整理后的英文 Colab 笔记本；按说明选择任务，不会默认启动付费训练。
- `TRAINING.md`：训练方式、云盘和 checkpoint 依赖。
- `RESULTS.md`：各对照结果及解释。
- `manifest.json`：包内文件的 SHA256 校验值。
- `CLEANUP.md`、`cleanup.json`：清理记录。

## CER、WER 与地名指标分开看

此前冻结配置的 500 行 HTR 测试结果为 CER **13.3917%**、WER **38.6088%**，使用 seed44 DE20、beam8、字符/词重评分权重 0.03/0.03。

CER、WER 是整行文字识别的错误率，不是地名专项错误率。此次整理没有重新训练或进行新的 HTR 测试；官方正文上的地名评价也不能替代图像到文字的测试。
